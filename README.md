# 👔 StyleSphere AI

An AI-powered multi-vendor fashion marketplace that combines modern e-commerce with AI-powered fashion assistance.

## 🚀 Features

- Multi-vendor Marketplace
- AI Stylist
- AI Outfit Recommendation
- Virtual Try-On
- Smart Product Search
- Wishlist
- Shopping Cart
- Order Tracking
- Vendor Dashboard
- Admin Dashboard
- Customer Dashboard
- Razorpay Payment
- Product Reviews
- Analytics Dashboard
